## When to amend

A report has been **released** and is wrong. The clinician may have read it and
acted on it.

If the report has not been released, simply correct the value in result entry.
Amendment is for reports already in someone's hands.

## Why it is heavier than an edit

Silently changing a released result is the worst possible handling, because:

- The clinician may have acted on the original and never learns otherwise.
- The record no longer shows what was reported at the time a decision was made.
- If the case is reviewed, the laboratory cannot show what it actually said.

> CAP requires that the original result be retained and remain visible, the
> report be clearly marked as amended, and the requesting clinician be notified.

## Tutorial

### Step 1 — Open the released report

**Reports** → find it → **Open** → **Amend**.

Only completed reports can be amended. If the order is not released, you are
sent back to result entry.

### Step 2 — Choose the result and the correction

Select which analyte is wrong and enter the corrected value. The current value
is shown; entering the same value is refused — there would be nothing to amend.

### Step 3 — Give a reason

| Reason | Use when |
| --- | --- |
| **Transcription error** | The value was mistyped |
| **Analytical error** | The measurement itself was wrong |
| **Specimen identification error** | The result belonged to another specimen |
| **Interpretation change** | The interpretation changed on review |
| **Addendum** | Adding information, not correcting |

Reason drives investigation. A transcription error suggests a data-entry
control; a specimen identification error is far more serious and almost never
affects only one sample.

### Step 4 — Write the narrative

This is printed on the amended report. Write it for the clinician:

> *"Potassium originally reported as 3.4 mmol/L. On review the sample was
> haemolysed and the result was not suppressed. Corrected value 5.1 mmol/L on a
> repeat specimen collected the same day."*

Say what was wrong, what it should be, and whether the original could have
misled.

### Step 5 — Confirm the clinician has been told

Tick that they have been told, and record how. **Do this before submitting** —
the amendment records that it happened.

A corrected report sitting in a system nobody re-reads has not corrected
anything. Telephone them.

### Step 6 — Sign it

Your password. An amendment is an electronic signature like any other.

## What happens

1. The original value is **kept** and printed on the amended report.
2. The report is marked **AMENDED** with a version number.
3. Your signature is recorded against the correction.
4. A **nonconformance is opened automatically**, flagged as patient impact — a
   report that went out wrong is a nonconformance by definition.
5. The audit trail records the change.

## Afterwards

Complete the nonconformance: root cause, corrective action, effectiveness check.

And ask the question that matters most: **did this affect other patients?** A
transcription error is usually isolated. A specimen mix-up, a calibration
problem or a suppression rule that failed almost never is.
